# R66S-Cooler
这个项目是一个为电犀牛R66S设计的散热器方案。目前仅包含基本可用的外壳模型，并目标支持使用USB控制和获取转速。

# 模型
模型目前包含三个部分，分别是散热器的基座、单片机外壳和USB外壳。  
基座：适用于任何8cm风扇；  
单片机外壳：适用于Yourcee STM32F103C6T6开发板，链接：https://detail.tmall.com/item.htm?id=1004313905043 ；  
USB外壳：适用于浮太 USB焊线插头带板（向上款），链接：https://detail.tmall.com/item.htm?id=754388652133 。  
目前的模型和线路以5V的四线PWM风扇为参考设计。
